БЫСТРЫЙ ЗАПУСК — «ТТН», ВЕРСИЯ «0.1.1»

Нужно: Windows и Python «3.10» или новее. Установка библиотек не требуется.

1. Распакуйте архив целиком в обычную папку с правом записи.
2. Дважды нажмите «start.cmd». Откроется окно программы в браузере.
3. Откройте «Настройка при передаче», вставьте «ссылку Smartup», проверьте
   «ссылку Didox», укажите «ИНН организации» и «адрес погрузки». Сохраните.
4. Скачайте шаблон, внесите список СФ и загрузите его. Исправьте ошибки
   в таблице, нажмите «Проверить изменения», сохраните отчёт или список.

Сейчас работают: загрузка XLSX/CSV, проверки, исправления, выгрузка.
Для получения данных из Didox/Smartup, создания и подписания ТТН разработчик
должен завершить интеграцию. Простое сохранение ссылок её не включает.
Задание для разработчика — «HANDOFF.md». Подписание: после проверки черновиков.

Если окно не открылось: запустите «check.cmd», посмотрите строки «ОШИБКА».
Обычный адрес: «http://127.0.0.1:8765/». Если порт занят, точный новый адрес
будет в окне консоли. При отсутствии Python установите его с python.org
и повторите запуск. На компьютере с Codex может использоваться его Python.

Остановка: закройте консоль. Повторный запуск: «start.cmd».
Сохраните исправленный список перед закрытием или обновлением страницы.

Настройки: «config.local.json» рядом с программой, создаётся после сохранения.
Перед обновлением оставьте себе копию этого файла. При ручной настройке
можно скопировать «config.example.json» как «config.local.json» и заполнить.
Пустые поля означают «ещё не задано»; локальная проверка списков доступна.
Пароли и ЭЦП этот файл не хранит. Исходный Excel остаётся без изменений.
