БЫСТРЫЙ ЗАПУСК — «ТТН», ВЕРСИЯ «0.2.0»

Нужно: Python «3.10+», доступы API Didox/Smartup; для подписи E-IMZO.
Для локальной демонстрации нужны только Python и исходный код.

1. Распакуйте проект, откройте «start.cmd».
2. Сохраните «ИНН организации», API-адреса, «project_code», «filial_id»
   и при необходимости «filial_code» Smartup.
3. Введите доступы и нажмите «Войти и проверить доступы».
   Didox: партнёрский токен + пароль, пользовательский токен либо ЭЦП.
   Smartup: логин/пароль с доступом к API и нужной организации.
4. Загрузите справочники Didox, выберите регион/район/адрес погрузки,
   при необходимости склад и сохраните настройки. Водителей получите кнопкой
   «Получить водителей из Smartup» за период «1–7» дней: дополните госномер,
   модель и ПИНФЛ и сохраните прямо в таблице. Загрузка CSV — второй вариант.
5. Скачайте пустой Excel-шаблон, заполните реальными ID СФ и загрузите его.
   Рядом доступен пример с тремя тестовыми СФ — его ID нужно заменить своими.
   Либо откройте «Получить список СФ из Didox по фильтрам»: выберите период,
   статус и при необходимости ИНН покупателя. Организация берётся из настроек.
   Нажмите «Получить список из Didox», при необходимости загрузите ещё страницы,
   отметьте одну СФ и нажмите «Подготовить 1 СФ». Выбранный список можно скачать
   в Excel кнопкой «Скачать выбранный список».
   Прочитайте ошибки и предупреждения в карточке.
6. Проверьте JSON: адрес доставки, водитель/ПИНФЛ, массу и единицы, расстояние.
   Недостающее заполните, нажмите «Проверить и сохранить JSON». Цены, товары,
   количества и суммы должны совпадать с исходной СФ.
7. Проверьте официальный способ привязки к СФ в вашем Didox. Отметьте проверку,
   нажмите «Создать выбранные черновики», откройте PDF и сверьте результат.
8. После первой СФ загрузите две–три, выберите их и нажмите «Подготовить
   выбранные СФ». Дальнейшие действия те же. Ошибка одной строки не скрывает
   результаты остальных; за один запрос обрабатывается до «50» СФ.
9. Для подписи загрузите ключи E-IMZO, выберите нужный ключ и черновики,
   нажмите «Подписать и отправить выбранные». Пароль ключа вводится в E-IMZO.

Демонстрация без аккаунтов: python tools/demo_integration.py
Одна СФ: «examples/integration_one.csv»; три: «examples/integration_three.csv».
В шапке «локальный имитатор»; реальные документы и ЭЦП не используются.
Результаты демонстрации не подтверждают работу на аккаунтах заказчика.

При ошибке запуска: «check.cmd». При истечении сеанса: войдите повторно.
Обычный адрес «http://127.0.0.1:8765/»; точный адрес напечатан в консоли.
Если повреждён «config.local.json», сохраните копию и переименуйте исходный
файл, затем запустите программу с настройками по умолчанию.

При неизвестном результате сначала найдите документ в Didox и введите его ID
в карточке для сверки. Если проверили отсутствие ТТН, явно отметьте это
перед разрешением повтора. Автоматического повтора записи нет.

Остановка: закрыть консоль; повторный запуск: «start.cmd» и повторный вход.
При обновлении сохраните «config.local.json» и «local-data/» с журналом.
Изменения списка перед закрытием страницы сохраните отдельным XLSX.

Настройки и детали: «INTEGRATION.md». Правила: «HANDOFF.md».
Код проверен на имитаторе; живые права, поля, связь СФ/ТТН и ЭЦП ещё требуют
проверки. Ссылки без API-доступов не подключают системы.
