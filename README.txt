ОБРАБОТЧИК СПИСКА СФ ДЛЯ ТТН — ВЕРСИЯ «0.1.1»

Короткая инструкция запуска: «RUNBOOK.txt».
Техническое задание принимающему разработчику: «HANDOFF.md».
Настройки ссылок и реквизитов: раздел «Настройка при передаче» в окне.

Запуск в Windows
1. Распакуйте весь архив в отдельную папку.
2. Дважды нажмите «start.cmd».
3. В браузере откроется локальное окно обработчика.
4. Для остановки закройте окно консоли или нажмите в нём Ctrl+C.

На этом компьютере запуск использует встроенный Python из Codex, если он
доступен. На другом компьютере нужен Python версии «3.10» или новее.
Дополнительные библиотеки Python и интернет для локального режима не нужны.
Альтернативный запуск из папки приложения: python app.py

Как пользоваться
1. Нажмите «Скачать пустой шаблон Excel» или возьмите готовый список XLSX/CSV.
2. В каждой строке укажите «ID СФ» либо три поля вместе:
   «Номер СФ», «Дата СФ», «ИНН клиента».
3. Загрузите файл кнопкой «Загрузить Excel или CSV» либо перетащите его.
4. Посмотрите результат каждой строки. Ошибки можно исправить прямо в окне,
   после чего нажать «Проверить изменения».
5. Сохраните отдельный «Отчёт» в CSV и/или «Выбранный список» в XLSX.
   Сохранённый XLSX можно снова загрузить в обработчик.

Что проверяется
— «ID СФ»: 32 шестнадцатеричных символа. Допускается UUID с дефисами или
  HTTPS-ссылка Didox с одним таким ID. Ссылки программа не открывает.
— Если «ID СФ» не указан, обязательны «Номер СФ», «Дата СФ», «ИНН клиента».
— «Дата СФ»: существующая дата. Поддерживаются даты Excel, «ДД.ММ.ГГГГ»
  и «ГГГГ-ММ-ДД». Формат «ДД/ММ/ГГГГ» также распознаётся.
— «ИНН клиента»: 9 цифр; для ПИНФЛ допустимы 14 цифр.
— Повторы по «ID СФ» или сочетанию «Номер СФ», «Дата СФ», «ИНН клиента».
— Противоречия: например, один «ID СФ» с разными «датами СФ» или одна
  комбинация реквизитов с разными «ID СФ». Такие строки требуют проверки.
— Формулы и ошибки Excel в используемых ячейках. Формулы не вычисляются;
  значения нужно вставить обычным текстом или датой.

В XLSX читается лист «Список СФ», если он есть, иначе единственный подходящий
лист. Если подходящих листов несколько, появится выбор. Заголовки должны
находиться в первых 20 строках. Пустые строки и посторонние колонки, включая
пояснения в шаблоне, не обрабатываются. Лимит: «5000» СФ, файл до «15» МБ.
Старый формат XLS нужно пересохранить в XLSX.

Что означает результат
«Список проверен» — реквизиты строки прошли локальную проверку.
Это ещё не подтверждает существование документа в Didox или его связь
с заказом Smartup. Для этого потребуется подключение систем.
«Повтор» — та же СФ уже представлена другой строкой; выбирается одна запись.
«Нужно исправить» — отсутствуют или некорректны реквизиты.
«Противоречие в списке» — связанные строки содержат несовместимые реквизиты.

Текущий этап
Вход в Didox/Smartup и создание, подписание, отправка ТТН ещё не подключены.
Кнопка «Создать черновики ТТН» поэтому недоступна. Обработчик не запрашивает
логины, пароли или ЭЦП и не выполняет запросы к этим системам.

Согласованные правила будущего подключения
— Обрабатываются только СФ из загруженного списка.
— «Одна СФ → одна ТТН», со всеми товарными строками СФ.
— Поиск заказа Smartup по «ИНН», «дате СФ» и «Стоимости поставки
  с учётом НДС» из СФ. Неоднозначные совпадения требуют выбора.
— «Стоимость груза» в ТТН переносится без НДС. Это отличается от суммы
  с НДС, используемой для поиска заказа.
— Один постоянный «адрес погрузки», выбираемый при настройке из Didox.
— После просмотра и исправления черновиков — «Подписать и отправить»
  выбранные ТТН с ЭЦП. Эти операции в версии «0.1.1» ещё недоступны.

Данные
Сервер слушает только локальный адрес «127.0.0.1»; обычно порт «8765».
Загруженный файл читается в памяти, исходный файл не изменяется.
Исправления живут в текущем окне до перезагрузки: сохраните выбранный список,
если хотите продолжить позже. Выгрузки сохраняются отдельно через браузер.
Отчёт CSV защищает текстовые значения от выполнения как формул при открытии
в Excel. Выбранный список XLSX сохраняет идентификаторы как текст.
