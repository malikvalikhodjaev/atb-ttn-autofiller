# Проверка локального обработчика без доступов

Все значения в «sf_demo.csv» синтетические. Эти СФ не нужно искать в реальных
системах или использовать для создания документов.

1. Запустить «start.cmd», загрузить «sf_demo.csv» через кнопку выбора файла.
2. Ожидается «4» строки: «2» проверены, «1» повтор, «1» требует исправления.
   Строка исходного файла «3» повторяет «2»; у строки «4» короткий «ИНН клиента».
3. В строке «4» заменить «ИНН клиента» на «012345678» и нажать
   «Проверить изменения»: «3» проверены, «1» повтор, ошибок нет.
4. Скачать отчёт CSV и выбранный список XLSX. В отчёте «4» строки данных,
   в выбранном списке — «3», если оставлены все проверенные СФ.
5. Загрузить сохранённый XLSX: «3» проверенные строки, без повторов и ошибок;
   «Номер СФ» сохранён как «00078/11», «ИНН клиента» — «012345678».

Кнопка создания ТТН остаётся отключённой; реальные подключения не выполняются.
Исправления в окне не меняют исходный CSV. Для своего задания используйте
пустой шаблон «templates/sf_upload_template.xlsx».
